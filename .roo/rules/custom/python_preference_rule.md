# Python First Language Rule

- **Author**: Tohar Laufer
- **Date**: 2025-06-06
- **Version**: 1.0.0
- **Priority**: High

## Description
This rule establishes Python as the primary and preferred programming language for all development within this project. When creating new scripts, tools, or any other code, Python should be the first choice unless there is a compelling technical reason to use another language.

## When to apply
- When starting any new coding task, script, or service.
- When choosing a language for a new feature or module.
- When a task can be reasonably accomplished in Python.

## When not to apply
- When a specific technology or platform requires a different language (e.g., frontend web development using JavaScript, or specific infrastructure-as-code tools).
- When an existing part of the project is written in another language and it's more practical to maintain consistency.
- When performance constraints demonstrably and significantly favor another language for a specific, critical component.
